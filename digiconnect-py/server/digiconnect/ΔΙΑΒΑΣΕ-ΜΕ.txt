DigiConnect — SERVER 2.0.5  (ιστοσελίδα + control panel + αναβαθμίσεις/demo/άδεια + «ποιοι είναι online»)
=======================================================================================================
ΠΟΥ ΜΠΑΙΝΕΙ
  Ο φάκελος `digiconnect` πάει στο web root ΔΙΠΛΑ στο `hamdigi`:
      .../hamdigi/
      .../digiconnect/        <-- εδώ    (→ https://hellaszone.com/digiconnect/)
  Η βάση είναι δική του (data/digiconnect.db). ΔΕΝ αγγίζει το HAM Digi.

ΠΡΩΤΗ ΕΓΚΑΤΑΣΤΑΣΗ
  1) Μετονόμασε `config.sample.php` → `config.php` και βάλε δικό σου admin_user / admin_pass.
  2) Ο φάκελος πρέπει να είναι εγγράψιμος από τον web server (φτιάχνεται μόνος του ο `data/`).
  3) Στον φάκελο `pkg/` βάλε τα αρχεία λήψης που βγάζει το GitHub (Actions → τελευταίο run → Artifacts):
        DigiConnect-Setup.exe · DigiConnect-macOS-Intel.dmg · DigiConnect-macOS-AppleSilicon.dmg · DigiConnect-Linux-x86_64.tar.gz
     Η ιστοσελίδα δείχνει κουμπί λήψης μόνο για όσα υπάρχουν.

ΑΝΑΒΑΘΜΙΣΗ ΑΠΟ ΠΡΟΗΓΟΥΜΕΝΟ server
  Ανέβασε ΟΛΑ τα αρχεία πάνω στα υπάρχοντα, ΕΚΤΟΣ από: config.php, data/, pkg/ (αυτά είναι δικά σου — μην τα αντικαταστήσεις).
  Η βάση αναβαθμίζεται μόνη της (προστίθενται στήλες για το «online») — δεν χάνεται τίποτα.

ΤΙ ΕΧΕΙ ΤΟ PANEL  (…/digiconnect/admin/)
  • Είσοδος με «Να με θυμάται» (180 ημέρες σε αυτόν τον υπολογιστή). Η «Αποσύνδεση» το ακυρώνει.
  • Δεξιά λίστα «Σταθμοί»: ποιοι είναι online τώρα (πομποδέκτης με πράσινο), ποιος ΕΚΠΕΜΠΕΙ (πορτοκαλί, TX),
    τι ακούει ο καθένας, και όσοι ήταν online τις τελευταίες 7 ημέρες. Ανανεώνεται μόνη της κάθε 30″.
  • Επισκόπηση · Στατιστικά · Εκδόσεις · Εγκαταστάσεις (demo/ενεργοποίηση/κλείδωμα/ενεργό-ανενεργό) ·
    Λήψεις/Εγγραφές · Άδειες/Κωδικοί · Servers/Λίστες · Μηνύματα · Δραστηριότητα · Ρυθμίσεις.
  • Γλώσσες EL/EN/SV, θέμα Auto/☀/☾, έκδοση server στην πλαϊνή στήλη και στο υποσέλιδο.

ΠΩΣ ΦΑΙΝΕΤΑΙ ΕΝΑΣ ΣΤΑΘΜΟΣ «ONLINE»
  Το πρόγραμμα (από την 2.0.3) στέλνει κάθε ~60″ στο `ping.php`: id εγκατάστασης, έκδοση, σύστημα,
  διακριτικό, locator, τι ακούει / σε ποιον εκπέμπει, και αν πατάει PTT. ΔΕΝ στέλνεται ήχος ούτε κωδικοί.
  Ο χρήστης μπορεί να το κλείσει: Ρυθμίσεις › Ο σταθμός μου › «Εμφάνιση του σταθμού μου ως online…».
  Σταθμός θεωρείται online όσο το σήμα του είναι νεότερο από 3 λεπτά. Παλιότερες εκδόσεις προγράμματος (πριν την 2.0.3)
  δεν στέλνουν σήμα, οπότε εμφανίζονται μόνο στα «Πρόσφατα» με την ώρα του τελευταίου ελέγχου αναβάθμισης.

ENDPOINTS ΠΟΥ ΚΑΛΕΙ ΤΟ ΠΡΟΓΡΑΜΜΑ
  manifest.php (έλεγχος αναβάθμισης + demo/άδεια) · api.php (licCheck / redeem) · download.php (.dcpkg) ·
  ping.php (σήμα online) · hosts/get.php (λίστες servers).

ΝΕΑ ΕΚΔΟΣΗ ΠΡΟΓΡΑΜΜΑΤΟΣ (χωρίς νέα εγκατάσταση — ΕΝΑ αρχείο)
  Το  DigiConnect-<έκδοση>.dcpkg  (artifact «DigiConnect-update-package-dcpkg» του GitHub) είναι το ίδιο για Windows, Mac, Linux.
  Panel → Εκδόσεις → «Ανέβασμα νέας έκδοσης» → διάλεξε το .dcpkg (έκδοση και ελάχιστο shell διαβάζονται μόνα τους)
  → «Ενεργοποίηση» ή «Επιβολή σε όλους». Οι εφαρμογές το κατεβάζουν μόνες τους.

ΛΙΣΤΕΣ SERVERS (Servers / Λίστες)
  «Ανανέωση τώρα» κατεβάζει τις δημόσιες λίστες (DMR/YSF/D-STAR/NXDN/P25/M17…) και τις δημοσιεύει στο hosts/pub
  (ή στο data/hosts αν το hosts/pub δεν είναι εγγράψιμο — τότε σερβίρονται από hosts/get.php).
  Δικοί σου σταθμοί: βάλε αρχεία στο hosts/custom/ (οδηγίες στο hosts/custom/ΔΙΑΒΑΣΕ-ΜΕ.txt) — εμφανίζονται πρώτοι.
  Αν δεις «ΜΗ εγγράψιμο» στο hosts/pub: chmod 775 digiconnect/hosts/pub.
