DigiConnect 2.3.8 — Release notes / Σημειώσεις έκδοσης / Versionsnoteringar
===========================================================================

ΕΛΛΗΝΙΚΑ
--------
ΝΕΑ ΣΤΗΝ 2.3.8 — ΔΙΟΡΘΩΣΗ ΤΗΣ ΣΕΛΙΔΑΣ ΧΑΡΤΗΣ
• ΔΙΟΡΘΩΘΗΚΕ: ο Χάρτης ήταν ακίνητος, χωρίς zoom, και δεν φαινόταν ποιος είναι ποιος. Τώρα: zoom με το ροδάκι, με τα κουμπιά + / − (⟲ = όλος ο κόσμος) και με διπλό κλικ· μετακίνηση με σύρσιμο.
• Ένας κύκλος ανά χώρα με τον αριθμό των σταθμών της (όχι πια ένα σημείο ανά σταθμό σε σπείρα). Το ποντίκι πάνω σε κύκλο δείχνει χώρα, δίκτυα και διακριτικά· κλικ διαλέγει τη χώρα (zoom + φίλτρο του πίνακα). Νέα λίστα «Χώρα» πάνω από τον χάρτη (π.χ. «Sweden (14)»). Κλικ σε γραμμή του πίνακα διαλέγει τη χώρα της.
• Σταθμός με γνωστό τετράγωνο (grid) από τον server είναι τελεία στη θέση του με το διακριτικό του. Υπόμνημα δικτύων με αριθμούς κάτω από τον χάρτη.
• ΔΙΟΡΘΩΘΗΚΕ: οι ΗΠΑ, η Τουρκία και περίπου 100 ακόμη χώρες και νησιά (Σιγκαπούρη, Μάλτα, Μονακό …) δεν ζωγραφίζονταν καθόλου επειδή το όνομά τους δεν ταίριαζε με το περίγραμμα. Μόνο το «European Union» δεν έχει θέση και μετριέται ως «εκτός χάρτη».
• Ελληνικά για όλα τα κείμενα της σελίδας. Νέα τεστ (tests/test_map.py).
• Αλλαγή στο πρόγραμμα: αρκεί η αυτόματη ενημέρωση ή ο installer. Ο server δεν άλλαξε σε σχέση με την 2.3.7.

ΝΕΑ ΣΤΗΝ 2.3.7 — ΑΝΤΙΓΡΑΦΑ ΑΣΦΑΛΕΙΑΣ ΤΗΣ ΒΑΣΗΣ ΤΟΥ SERVER
• ΝΕΟ (πάνελ, σελίδα «Αντίγραφα βάσης»): αυτόματο αντίγραφο ολόκληρης της βάσης (εγκαταστάσεις, άδειες, κωδικοί, πληρωμές, μηνύματα, συνομιλίες, ρυθμίσεις) ΚΑΘΕ ΩΡΑ· κρατιούνται τα τελευταία 10 και το παλαιότερο αντικαθίσταται. Κουμπί «Δημιουργία αντιγράφου τώρα», «Λήψη» κάθε αντιγράφου, «Επαναφορά» με ένα κουμπί (κρατιέται πρώτα αντίγραφο της τρέχουσας κατάστασης, άρα η επαναφορά αναιρείται) και επαναφορά από αρχείο .sqlite του υπολογιστή σου. Προειδοποίηση στην Επισκόπηση όταν δεν υπάρχει πρόσφατο αντίγραφο.
• Το πρόγραμμα DigiConnect δεν άλλαξε σε σχέση με την 2.3.6· η αλλαγή είναι στον server (ανέβασε ΟΛΑ τα αρχεία του φακέλου digiconnect).

ΝΕΑ ΣΤΗΝ 2.3.6 — ΔΙΟΡΘΩΣΕΙΣ
• ΔΙΟΡΘΩΘΗΚΕ: Listen / Connect (TX) / PTT ξανά και μέσα στη σελίδα κάθε δικτύου (τα είχα κρύψει όταν μπήκε η σταθερή μπάρα κάτω· η μπάρα κάτω μένει).
• ΔΙΟΡΘΩΘΗΚΕ: My favorites με επιλεγμένη χώρα έδειχνε 0 — το φίλτρο χώρας ισχύει μόνο στον κατάλογο, όχι στα αγαπημένα.
• ΔΙΟΡΘΩΘΗΚΕ: ένα TG της λίστας (π.χ. 930 PanHellenic Chat) χωρίς πρόθεμα χώρας κρυβόταν από το φίλτρο χώρας και αντικαθίστατο από γραμμή «typed number»· τώρα δείχνεται όπως το δίνει η λίστα.
• ΔΙΟΡΘΩΘΗΚΕ: D-Star, π.χ. XLXQRZ B: δεν συμπληρωνόταν διεύθυνση/πόρτα όταν ο reflector είναι στη λίστα DCS αλλά το όνομα αρχίζει από XLX. Τώρα ψάχνει σε όλες τις λίστες. Νέο τεστ: κάθε εγγραφή κάθε λίστας βρίσκει διεύθυνση.
• ECHOLINK: η λίστα σταθμών διαβάζεται ακριβώς όπως την διαβάζει το SvxLink (@@@, πλήθος, 4 γραμμές ανά σταθμό, +++· τα μηνύματα του directory δεν είναι σταθμοί· «INCORRECT PASSWORD» εμφανίζεται ως έχει) και η σύνδεση στέλνει τις ίδιες λέξεις κατάστασης (ONLINE3.38, BUSY3.40, OFF-V3.40). Δεν έχει δοκιμαστεί με πραγματικό λογαριασμό από το περιβάλλον κατασκευής.
• Server (πάνελ Modes): το «για όλους» και το «σε επιλεγμένους» είναι πλέον ένα: η αλλαγή «για όλους» ισχύει σε ΟΛΕΣ τις εγκαταστάσεις (σβήνει τις δικές τους ρυθμίσεις *) και αν τσεκάρεις όλες τις εγκαταστάσεις αλλάζει και η γενική ρύθμιση. Ανέβασε ΟΛΑ τα αρχεία του φακέλου digiconnect.

ΝΕΑ ΣΤΗΝ 2.3.5 — ΔΙΟΡΘΩΣΕΙΣ ΣΤΗΝ ΕΚΚΙΝΗΣΗ ΚΑΙ ΣΤΗΝ ΕΚΠΟΜΠΗ + ΜΙΚΡΟΦΩΝΟ, ΧΑΡΤΗΣ, ΗΧΟΓΡΑΦΗΣΕΙΣ, ECHOLINK
• ΔΙΟΡΘΩΘΗΚΕ: το εγκατεστημένο πρόγραμμα δεν ξεκινούσε (Windows: «No such file … world110.json»· Mac: σταματούσε χωρίς μήνυμα). Το αρχείο του χάρτη δεν μπήκε στο πακέτο. Το πακέτο Linux δεν έβρισκε τη μηχανή. ΝΕΟ τεστ: το ΕΤΟΙΜΟ πρόγραμμα ξεκινά και ανοίγει όλες τις σελίδες σε κάθε σύστημα πριν δοθεί.
• ΔΙΟΡΘΩΘΗΚΕ: σφάλμα στην εκκίνηση («dictionary update sequence element #0 has length 1») όταν είχε επιλεγεί μικρόφωνο. Η σελίδα Μικρόφωνο έγραφε τις ρυθμίσεις της στο κλειδί που κρατά το όνομα της συσκευής. Τώρα έχουν χωριστό κλειδί (mic_fx)· παλιές ρυθμίσεις μεταφέρονται αυτόματα.
• ΔΙΟΡΘΩΘΗΚΕ: το δεύτερο πάτημα PTT έκλεινε τη μηχανή (βρέθηκε και επιβεβαιώθηκε σε macOS Intel με AddressSanitizer)· ο δείκτης της συσκευής καταγραφής διαγραφόταν από το Qt.
• Νέα τεστ: κάθε σελίδα ανοίγει με ρυθμίσεις πραγματικού χρήστη· η σελίδα Μικρόφωνο δεν αγγίζει τα ονόματα συσκευών.
• ΝΕΟ: Μικρόφωνο (ενίσχυση, μπάσα/μεσαία/πρίμα, φίλτρο υψηλών, noise gate, συμπιεστής, στάθμη εξόδου, limiter), Χάρτης, Ηχογραφήσεις και κουμπί Record, EchoLink (δοκιμασμένο μόνο με προσομοιωμένο σταθμό), ενεργοποίηση/απενεργοποίηση mode από την καρτέλα, σταθερή μπάρα ελέγχου.
• Server: ανέβασε ΟΛΑ τα αρχεία του φακέλου digiconnect (νέο online.php για τη σελίδα Χάρτης).
• Ο κώδικας της μηχανής άλλαξε: χρειάζεται ο πλήρης installer (η αυτόματη ενημέρωση δεν αντικαθιστά τη μηχανή).

ENGLISH
-------
NEW IN 2.3.8 — FIX OF THE MAP PAGE
• FIXED: the Map was static, could not zoom, and you could not tell who was who. Now: zoom with the wheel, the + / − buttons (⟲ = the whole world) and double-click; move by dragging.
• One circle per country with its number of stations (no more one point per station in a spiral). Hover a circle for country, networks and call signs; a click chooses the country (zoom + filter of the table). A new "Country" box above the map (e.g. "Sweden (14)"). A click on a table row chooses its country.
• A station with a known grid square from the server is a dot at its place with its call sign. Legend with numbers per network under the map.
• FIXED: the United States, Türkiye and about 100 more countries and islands (Singapore, Malta, Monaco …) were not drawn at all because their name did not match the outline. Only "European Union" has no place and is counted as "not on the map".
• Greek for all texts of the page. New tests (tests/test_map.py).
• Change in the program: the automatic update or the installer is enough. The server is unchanged from 2.3.7.

NEW IN 2.3.7 — BACKUPS OF THE SERVER DATABASE
• NEW (panel, page "Database backups"): an automatic copy of the whole database (installations, licences, codes, payments, messages, chats, settings) EVERY HOUR; the last 10 are kept and the oldest is replaced. Button "Create a backup now", "Download" for every copy, one-button "Restore" (a copy of the current state is kept first, so a restore can be undone) and restore from a .sqlite file on your computer. A warning on the Overview when there is no recent copy.
• The DigiConnect program itself is unchanged from 2.3.6; the change is on the server (upload ALL files of the digiconnect folder).

NEW IN 2.3.6 — FIXES
• FIXED: Listen / Connect (TX) / PTT are in the page of every network again (I had hidden them when the fixed bar at the bottom was added; the bar at the bottom stays).
• FIXED: My favorites with a country chosen showed 0 — the country box filters the directory only, not the favorites.
• FIXED: a talkgroup of the list (e.g. 930 PanHellenic Chat) without a country prefix was hidden by the country filter and replaced by a "typed number" line; it is shown as the list gives it.
• FIXED: D-Star, e.g. XLXQRZ B: no host/port was filled in when the reflector is in the DCS list but its name starts with XLX. All lists are searched now. New test: every entry of every list finds an address.
• ECHOLINK: the station list is read exactly as SvxLink reads it (@@@, count, 4 lines per station, +++; messages of the directory are not stations; "INCORRECT PASSWORD" is shown as it is) and the sign-in sends the same state words (ONLINE3.38, BUSY3.40, OFF-V3.40). Not tried with a real account from the build environment.
• Server (panel Modes): "for everyone" and "for selected" are one setting now: a change "for everyone" reaches ALL installations (their own settings * are removed) and ticking all installations also changes the general setting. Upload ALL files of the digiconnect folder.

NEW IN 2.3.5 — START-UP AND TRANSMIT FIXES + MICROPHONE, MAP, RECORDINGS, ECHOLINK
• FIXED: the installed program did not start (Windows: "No such file ... world110.json"; Mac: stopped without a message). The map file was missing from the package. The Linux package could not find its engine. NEW test: the BUILT program is started and every page opened on each system before release.
• FIXED: start-up error ("dictionary update sequence element #0 has length 1") when a microphone had been chosen. The Microphone page stored its values under the key that holds the device name. They now have their own key (mic_fx); old settings are moved automatically.
• FIXED: the second press of PTT closed the engine (found and confirmed on macOS Intel with AddressSanitizer); the capture-device pointer was deleted by Qt.
• New tests: every page opens with the settings of a real user; the Microphone page never touches the device names.
• NEW: Microphone (gain, bass/mid/treble, high-pass, noise gate, compressor, output level, limiter), Map, Recordings and the Record button, EchoLink (tested only against a simulated station), switching a mode on or off from its tab, one fixed control bar.
• Server: upload ALL files of the digiconnect folder (new online.php for the Map page).
• The engine code changed: use the full installer (the automatic update cannot replace the engine).
