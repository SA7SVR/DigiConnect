# Αυτόματη αναβάθμιση DigiConnect (χωρίς νέα εγκατάσταση)

## Πώς δουλεύει
1. Η εφαρμογή ρωτά το `https://hellaszone.com/digiconnect/manifest.php` (στην εκκίνηση και κάθε λίγες ώρες).
2. Αν υπάρχει νεότερη ενεργή έκδοση, κατεβάζει το `.dcpkg`, ελέγχει μέγεθος + SHA-256, ελέγχει ότι ο κώδικας μεταγλωττίζεται,
   και το αποθηκεύει στον φάκελο δεδομένων του χρήστη (`…/DigiConnect/updates/v<έκδοση>/`).
3. Την επόμενη εκκίνηση (ή με «Ενημερώσεις › Επανεκκίνηση τώρα») τρέχει ο νέος κώδικας. Τίποτα δεν αντικαθίσταται επιτόπου.
4. Αν η νέα έκδοση δεν ξεκινά ή καταρρεύσει στην εκκίνηση, απενεργοποιείται μόνη της και τρέχει ο κώδικας του προγράμματος.

## Τι ενημερώνεται με .dcpkg και τι όχι
* **Με .dcpkg (αυτόματα):** όλος ο κώδικας Python της εφαρμογής (`app/`), εικόνες, μεταφράσεις, λίστες, θέματα.
* **Με πλήρη εγκατάσταση (σπάνια):** η μηχανή πρωτοκόλλων `dcengine` (C++), το Qt/Python, νέες βιβλιοθήκες.
  Τότε ανεβαίνει νέο πρόγραμμα εγκατάστασης και ανεβαίνει το `SHELL_VERSION` στο `bootstrap.py`· οι παλιές εγκαταστάσεις
  δεν κατεβάζουν πακέτο που χρειάζεται νεότερο shell, αλλά ειδοποιούνται να κατεβάσουν τον πλήρη installer.

## Βήματα για κάθε νέα έκδοση
1. Αλλαγές στον κώδικα, αύξηση του `APP_VERSION` στο `app/version.py` (π.χ. 2.0.5). Το `BASE_VERSION` στο `bootstrap.py` ΜΕΝΕΙ ίδιο
   μέχρι να ξαναχτιστεί ο installer.
2. Push στο GitHub → το CI τρέχει τα τεστ και βγάζει το artifact **DigiConnect-update-package-dcpkg** (`DigiConnect-2.0.5.dcpkg`).
   (Τοπικά: `python3 tools/build_dcpkg.py 2.0.5`.)
3. Στο panel `…/digiconnect/admin/index.php?p=releases` → «Ανέβασμα νέας έκδοσης» → διάλεξε το `.dcpkg` (η έκδοση και το ελάχιστο shell
   διαβάζονται αυτόματα από το πακέτο) → Ανέβασμα → «Ενεργοποίηση» (ή «Επιβολή σε όλους»). Το rollout % επιτρέπει σταδιακή διάθεση.
4. Οι εγκατεστημένες εφαρμογές την παίρνουν μόνες τους.

## Πρώτη εγκατάσταση
Τα αρχεία από το GitHub Actions (Windows `DigiConnect-Setup.exe`, macOS `DigiConnect-macOS-Intel.dmg` / `DigiConnect-macOS-AppleSilicon.dmg`,
Linux `DigiConnect-Linux-x86_64.tar.gz`) ανεβαίνουν στον φάκελο `digiconnect/pkg/` του server· η ιστοσελίδα τα δείχνει ως κουμπιά λήψης.
