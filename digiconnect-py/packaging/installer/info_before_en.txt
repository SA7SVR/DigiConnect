DigiConnect 2.5.0 — HELLAS Zone (SA7SVR)
=====================================

What it is
  A program for radio amateurs that connects to digital-voice networks
  (DMR, D-STAR, C4FM/YSF, NXDN, P25, M17) to listen and to talk.
  You connect to any server in the world from the public lists.

What is new in this version (2.5.0)
  • NEW: the "VoIP" button is now a SIP telephone: sign in to your SIP server with your extension and password, see who is available (only what the server reports) and call colleagues. Use a headset (no echo cancellation yet). It has five settings tabs, ringtone choices and an account request from inside the program (no e-mail); the server owner can switch VoIP on and off from the panel.
  • Not yet tested with the HELLAS Zone FreeSWITCH/FusionPBX server and real Windows sound devices.
  New in 2.4.0:
  • NEW: automatic updates can now also bring a new protocol engine (the part with the protocols and the audio) without a new installer. The engine is downloaded first, checked and test-started; if it does not start, the program goes back to the one that came with the installer by itself.
  • NEW: the website explains the installation on Windows, Mac and Linux step by step (and the warning that appears the first time).
  • NEW EchoLink: the program waits 30 seconds for the station to answer (like the official program), then shows "Connected to <callsign · name>" next to Last heard (with or without a user list), plays a connect / disconnect tone (can be switched off in Settings > Audio) and "Stop listening" is ready at once. It has not been tried with a real station by the maker: please tell us what you see.
  • NEW AllStarLink: "Now talking" and Last heard now work from the real voice packets of the node (it shows "Node <number>": IAX carries no callsign).
  • NEW: a switched-off "VoIP" button, reserved for a later SIP phone. FIXED (server): the name of the extra was missing from the thank-you email after a payment.
  • The engine changed: this installer must be the first one you give to new users.
  New in 2.3.12:
  • NEW: a mode (for example AllStar) can be an "extra": it stays closed until an additional donation is made; the page shows the message and the Donate button with the amount, and it opens by itself after the payment.
  • NEW (Licence window): for a finished licence it shows "Licence: Permanent · DC-00001 · since <date>", the activation code, the name and the extras.
  New in 2.3.11:
  • FIXED: the Donate / Buy button now shows the amount you set in the server panel (for example "♥ Donate · 5 €"); until now the server sent it but the program never displayed it.

  • EchoLink: list in the order of the official program; not yet tested with a real connection.

  New in 2.3.3:
  • Listening shows the station that talks (callsign, name, country) in the tile and in a side panel; DTMF keypad; D-Star modules A-Z; one conversation with the owner.

  • "Licence" button in the top bar: licence status, activation code, messages from the owner with

  • Signed updates: only what the HELLAS Zone server signs is installed.
  • Bottom licence card with logo, installation number, licence and callsign.

  • EchoLink: connects with your own EchoLink account (call sign and password entered in the program).

    (the automatic update cannot replace the engine).

Before you continue
  If DigiConnect is open, Setup will close it. Your settings, favorites and
  history are NOT deleted.
